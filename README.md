<div align="center">

*I treat design as part of engineering: an AI feature is only as good as the interface that makes it understandable.*

<br/>

| 🎯 Principle | What it means in my work |
|:--|:--|
| **Clarity first** | Clean layouts and clear hierarchy, so users understand an AI result at a glance |
| **Feedback & trust** | Loading states, confidence cues and graceful errors around LLM outputs |
| **Consistency** | Reusable components and design tokens built with Tailwind and Storybook |
| **Accessibility** | Readable contrast, keyboard-friendly flows, responsive across devices |
| **Prototype → Ship** | Wireframe in Figma, validate quickly, then build in React / Next.js |
